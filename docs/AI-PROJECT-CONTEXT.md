# Project context and solution prompts

## What this adds

Each project can store Markdown context. A task can store solution prompts assembled from that context or generated by the signed-in user's OpenAI key. Quick capture can default to a project and labels inside the active workspace.

## Secrets

Set `AI_CREDENTIALS_KEY` on the API (16+ characters). It is the AES-256-GCM key for personal provider secrets. If it is unset, the API falls back to a value derived from `JWT_SECRET` and marks the key version as `0`. Do not put provider keys in `EXPO_PUBLIC_*`, web env files, or the database as plaintext.

Provider test and generation are rate-limited in process memory (5 tests and 8 generations per user per 10 minutes).

## Migration

Apply `apps/api/prisma/migrations/20261107000001_project_context_ai`.

```bash
pnpm --filter @doit/api exec prisma migrate deploy
```

The migration only adds tables. It does not rewrite tasks, attachments, or invitations.

## Rollback

```sql
DROP TABLE IF EXISTS "TaskSolutionPrompt";
DROP TABLE IF EXISTS "QuickCapturePreference";
DROP TABLE IF EXISTS "AiProviderCredential";
DROP TABLE IF EXISTS "ProjectContext";
DROP TYPE IF EXISTS "PromptGenerationStatus";
DROP TYPE IF EXISTS "AiCredentialStatus";
DROP TYPE IF EXISTS "AiProviderName";
```

Dropping these tables deletes saved context, prompts, preferences, and encrypted keys. It does not delete tasks or attachments. Take a backup first.

## Client behavior

There was no previous solution-prompt record type. The new task section is the only prompt generator. "Assemble from task" does not call a provider. "Generate with AI" does, and it refuses to replace a manually edited prompt unless the user confirms.
