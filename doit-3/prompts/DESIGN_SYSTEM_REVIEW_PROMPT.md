# Design System Agent Prompt

Audit and implement the Samyukt Pulse mobile design system before building feature-specific screens.

Read `UI_DESIGN_SYSTEM.md` and `ARCHITECTURE.md`. Establish semantic color tokens for system/light/dark mode and five accent palettes; spacing, typography, radius, elevation and motion tokens; reusable form controls, buttons, sheets, dialogs, chips, task rows, empty/loading/error states and floating navigation.

Requirements:
- Use one icon family and one component foundation.
- No hard-coded colors or arbitrary spacing in feature screens.
- Keep the UI compact, professional and calm; avoid excess empty space, glow, neon and unnecessary gradients.
- Ensure the floating bottom navigation handles safe areas, keyboard visibility and small screens.
- Include focus/pressed/disabled states, accessibility labels and text scaling.
- Provide a screen template and a checklist for future screens.
- Test the theme across representative screens before reporting completion.

Deliver: tokens, shared components, theme provider, screen template, usage documentation and tests. Do not implement business features in this phase.
